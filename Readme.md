
# FrameFind

FrameFind is a responsive image-search application that will help users discover images based on topics they enter.

The app uses a forest-green, cream, and coral colour palette to create a calm and welcoming visual experience.

I added category suggestion chips so users can quickly explore popular topics.

I used CSS Grid with auto-fill and minmax to make the future image results responsive across mobile, tablet, and desktop screens.
